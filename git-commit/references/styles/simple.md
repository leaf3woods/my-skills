# Simple Commit Style

Use for personal repositories or quick local commits when Conventional Commits are unnecessary.

## Format

```text
<imperative summary>
```

Optional body only when the change needs explanation.

## Rules

- Keep the first line concise.
- Use imperative mood.
- Do not add type prefixes.
- Do not add ticket keys unless the user asks.

## Examples

```text
Add Windows install suite
Update PR submission docs
Fix terminal profile detection
```
