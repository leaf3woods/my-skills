# Project Context

This bundled file is a placeholder until project background is provided.

## Required Output

Every handoff must include a `Predicted Work Repository` section with:

- Repository path or repository name.
- Confidence.
- Project context source path.
- Short reason.

## Default When Project Context Is Missing

- Repository: `Unknown`
- Confidence: `low`
- Reason: `Project background file is missing or still a placeholder.`

Replace this file or point `$env:JIRA_WORKFLOW_PROJECT_CONTEXT` to a project-specific background file when repository mapping rules are available.
