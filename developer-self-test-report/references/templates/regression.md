# Regression Self-Test Template

Use when the user asks for regression-oriented developer self-test notes.

```md
# Regression Self-Test Report

## Change Summary

<Business-level summary of what changed.>

## Direct Verification

- <Directly tested changed behavior.>

## Regression Focus

- <Related area that could be affected.>
- <Another concise focus area if useful.>

## Result

<Passed / Not run / Needs verification>
```

Rules:

- Focus on areas plausibly affected by the change.
- Avoid exhaustive QA matrices.
- Use `Needs verification` when evidence is insufficient.
